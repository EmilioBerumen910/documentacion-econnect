RDS Documentación (Econnect)

Fuente original: RDS-Documentacion-Econnect.pdf
Última generación de este sitio: 2026-03-04

Este sitio documenta el servicio de base de datos principal de la plataforma Econnect en AWS y los puntos que típicamente impactan una migración de región (origen us-east-1 → destino mx-central-1).

Servicio cubierto

  • Motor: Amazon RDS MariaDB
  • Instancia: econnectds1 (Single-AZ)
  • Región actual: us-east-1
  • Región destino: mx-central-1

Hallazgos clave (para migración)

  • La instancia está configurada como Publicly accessible = true, con acceso controlado por allowlists en Security Groups y NACLs.
  • El DB Subnet Group actual es público (subnets con ruta 0.0.0.0/0 al Internet Gateway).
  • No existe conectividad privada (sin Peering/TGW/VPN/Direct Connect) que afecte el acceso a econnectds1.
  • Cifrado en reposo (storage) NO está habilitado para RDS (StorageEncrypted: false).
  • Backups automáticos habilitados con retención de 1 día.
  • Performance Insights / Enhanced Monitoring / exports de logs: deshabilitados (visibilidad limitada).

Cómo correr el sitio

python -m pip install mkdocs
python -m mkdocs serve
