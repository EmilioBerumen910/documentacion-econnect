Networking (VPC) y conectividad

Estado actual

  • La mayoría de Lambdas no tienen VPC config.
  • En us-east-1, al menos estas Lambdas corren dentro de VPC: lambda-usuarios-dev y lambda-catalogos-dev.

VPC y subnets

  • VPC: vpc-0cda6f6b
  • Subnets privadas usadas (extraídas del reporte):
  • subnet-0ef552d2118b2938a
  • subnet-028170afb4e27690a
  • subnet-0d2549cfe1b691e62
  • subnet-0a083fd804a5d7647

Security Groups

SGs referenciados en la configuración VPC de Lambdas: - sg-fc671187 - sg-d98096ab - sg-0ba3113ad69e16a24

Hallazgo: se referencia un SG que no existe: sg-0ba3113ad69e16a24.
Recomendación: corregir/limpiar referencias antes de replicar la configuración en la región destino.

Salida a internet (NAT)

  • Las subnets privadas salen por NAT Gateway: nat-03f4861d918874e94.

VPC Endpoints

  • S3 Gateway Endpoint: vpce-0c4f93159068b2702.
  • No hay evidencia de endpoints para Secrets Manager / SQS / SNS / CloudWatch Logs (por lo que el tráfico puede ir vía NAT).
