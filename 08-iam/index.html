Modelo de acceso (operación)

  • Para instancias con AmazonSSMRoleForInstancesQuickSetup, el patrón esperado es:
  • Acceso interactivo vía SSM Session Manager
  • Operación/automatización vía SSM Run Command
  • Métricas/logs vía CloudWatch Agent (si configurado)

Pendientes para completar IAM

  • Confirmar roles e instance profiles de todas las instancias (incluyendo stopped).
  • Inventariar políticas inline/managed adjuntas a roles relevantes (especialmente si hay acceso a S3, SQS, RDS, parámetros SSM, etc.).
  • Validar si hay keys o accesos legacy (IAM users) usados por apps, y plan para eliminarlos.

Recomendaciones de hardening (si aplica)

  • Adoptar “least privilege”: roles separados por función (app, batch, reporting, automation).
  • Evitar permisos administrativos en roles de EC2 salvo casos puntuales y documentados.
