Documentación técnica de la plataforma (AWS)

Fuente: assets/EC2-Documentacion-Econnect.pdf
Generado: 2026-03-03

Esta documentación describe cómo está montada la plataforma en AWS (cuenta, red, EC2, entry points, dependencias, observabilidad y seguridad) con el objetivo de tener una base clara para operación y migración a mx-central-1.

Identificadores clave

  • Cuenta AWS: 305968097757
  • Regiones activas: us-east-1, us-east-2
  • Región destino (migración): mx-central-1
  • VPCs detectadas:
  • vpc-0cda6f6b (con subnets públicas y privadas; salida por NAT)
  • vpc-166c0773 (subnets públicas)

Arquitectura (vista rápida)

  • Frontend / sitios: CloudFront → S3 (CNAMEs observados: econnectpro.mx, www.econnectpro.mx, login.econnectpro.mx).
  • Apps detrás de ALB: 7 ALBs internet-facing en us-east-1 (econnect/admin/soluciona31/reportes/integra24/apivucem/apiSA31).
  • APIs: API Gateway en us-east-1 y us-east-2 (REST + WebSocket; además HTTP en us-east-2).
  • Cómputo principal: EC2 (Windows + Linux) y MongoDB self-hosted.
  • DB principal: RDS MariaDB econnectds1.
  • Mensajería: SQS (colas en us-east-1 y us-east-2).

Hallazgos de operación (alto nivel)

  • Hay monitoreo de CPU/Mem/Disk para algunas instancias (12 alarmas EC2) pero faltan alarmas para RDS/ALB/SQS/Lambda.
  • Exposición de red: se reportan puertos MongoDB (27017–27030) y 8881 abiertos a Internet; NACL permisiva.
  • Seguridad: SSM Session Manager se usa como acceso principal, pero sin logging/KMS/idle-timeout; además hay un SG con RDP (3389) abierto a 0.0.0.0/0 (hallazgo crítico).
