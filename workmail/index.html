WorkMail

Resumen de qué hace en Econnect

WorkMail opera el correo corporativo y colaboración básica de Econnect en us-east-1. SES queda separado para correo programático.

Arquitectura / flujo

Cliente de correo / usuarios -> WorkMail us-east-1

DNS de correo y autodiscover:

  • autodiscover.econnectpro.mx -> autodiscover.mail.us-east-1.awsapps.com
  • autodiscover.emanifiesto.mx -> autodiscover.mail.us-east-1.awsapps.com

Riesgos y gaps

  • Dependencia regional directa en us-east-1 para SMTP/IMAP/autodiscover.
  • emanifiesto.mx falla tanto en WorkMail como en SES.
  • No hay journaling/monitoring configurado.
  • No hay evidencia de forwarding.
  • No se evidenció recepción programática de aplicación vía WorkMail.

Runbook operativo

  1. Confirmar que la organización procontrol sigue activa.
  2. Revisar dominio afectado (econnectpro.mx / emanifiesto.mx).
  3. Probar SMTP/IMAP/autodiscover.
  4. Revisar reglas de access control y mobile device access.
  5. Confirmar que no exista forwarding o journaling pendiente no documentado.

Checklist de migración a mx-central-1

  1. Decidir si WorkMail se mantendrá regionalmente en us-east-1.
  2. Validar que DNS y autodiscover apunten al diseño final.
  3. Corregir emanifiesto.mx.
  4. Documentar buzones críticos y grupos.
  5. Probar clientes IMAP/SMTP y webmail después de cualquier cambio.
  6. Si habrá coexistencia regional, documentar claramente qué parte sigue en us-east-1.

Cómo validar

aws workmail list-organizations --region us-east-1
aws workmail describe-organization --organization-id m-01ec025f961a4b909c8f859a7926280e --region us-east-1
aws workmail list-mail-domains --organization-id m-01ec025f961a4b909c8f859a7926280e --region us-east-1

Cómo obtener la evidencia

aws workmail list-users --organization-id m-01ec025f961a4b909c8f859a7926280e --region us-east-1
aws workmail describe-user --organization-id m-01ec025f961a4b909c8f859a7926280e --user-id <user-id> --region us-east-1
aws workmail describe-email-monitoring-configuration --organization-id m-01ec025f961a4b909c8f859a7926280e --region us-east-1
aws workmail list-access-control-rules --organization-id m-01ec025f961a4b909c8f859a7926280e --region us-east-1
