SES

Resumen de qué hace en Econnect

Según el PDF, Amazon SES se usa como la capa de envío programático de correo, mientras que WorkMail se usa como correo corporativo. La operación visible de SES está concentrada en us-east-1.

Arquitectura / flujo

Aplicación/Lambda/EC2 (no probado directamente) -> SES en us-east-1 -> destinatarios

El PDF también demuestra una relación fuerte con WorkMail:

  • políticas de autorización de envío tipo workmail-m-01ec025f961a4b909c8f859a7926280e,
  • cuenta autorizada 427373581819,
  • y uso principal de WorkMail como emisor real observado.

Riesgos y gaps

  • emanifiesto.mx no está verificado correctamente aunque tenga registros DNS visibles.
  • carta.porte@econnectpro.mx está fallando y no puede enviar.
  • No hay Configuration Sets ni event publishing a SNS/EventBridge/CloudWatch.
  • No se detectaron eventos ses:SendEmail / SendRawEmail en CloudTrail; la auditoría de envío es débil.
  • mx-central-1 no aparece como región SES disponible en la evidencia.

Runbook operativo

  1. Verificar estado de la identidad afectada.
  2. Revisar DNS de dominio: SPF, DKIM, _amazonses, DMARC.
  3. Confirmar si el envío viene por WorkMail o por SES API.
  4. Revisar cuotas, rate y si el ambiente está realmente en producción.
  5. Si falla deliverability, revisar rebotes y quejas; hoy no hay Configuration Sets, así que esta visibilidad es limitada.

Checklist de migración a mx-central-1

  1. Confirmar si SES seguirá en us-east-1 o se moverá a otra región soportada.
  2. Inventariar qué flujos de aplicación envían correo.
  3. Corregir emanifiesto.mx y carta.porte@econnectpro.mx antes del cutover.
  4. Habilitar observabilidad mínima: VDM o Configuration Sets.
  5. Definir si WorkMail seguirá siendo el camino principal para correo corporativo.
  6. Probar envío desde la región/diseño objetivo y actualizar documentación de endpoint.

Cómo validar

Consola AWS

  1. SES > Configuration > Verified identities.
  2. SES > Account dashboard.
  3. Route 53 > Hosted zones > revisar TXT/CNAME/MX.

AWS CLI

aws sesv2 list-email-identities --region us-east-1
aws sesv2 get-email-identity --email-identity econnectpro.mx --region us-east-1
aws sesv2 get-account --region us-east-1

Cómo obtener la evidencia

aws sesv2 list-email-identities --region us-east-1
aws sesv2 get-email-identity --email-identity emanifiesto.mx --region us-east-1
aws route53 list-resource-record-sets --hosted-zone-id Z1FARNXLLG1M1C
aws route53 list-resource-record-sets --hosted-zone-id Z08820291VNSCOK6DWOW3
