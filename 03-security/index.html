Seguridad

Cifrado en reposo

  • RDS (econnectds1): NO cifrado (StorageEncrypted: false)
    Implica que storage y backups automatizados no están cifrados.
  • S3: cifrado habilitado (SSE-S3 mayormente, y algunos SSE-KMS)
  • EBS: estado mixto (parte cifrado/parte sin cifrar)
  • Snapshots/AMIs: sin cifrar (según evidencia consolidada)

KMS

  • RDS storage: N/A (no está cifrado).
  • (Referencia) KMS para otros componentes aparece como customer-managed en algunos casos (p. ej. llaves usadas por otros servicios).

TLS/SSL para conexiones

  • Cert CA reportado: rds-ca-rsa2048-g1 (vence 2026-09-08).
  • Enforcement de TLS: no se observa forzado desde parameter group (conclusión: no obligatorio).
  • Mitigación rápida (recomendada): forzar TLS desde el cliente/driver (p. ej. ssl-mode=REQUIRED) y planear enforcement formal en configuración cuando sea viable.

Autenticación IAM a la DB

  • IAM DB Authentication: NO (IAMDatabaseAuthenticationEnabled: false).
    La autenticación es por usuario/password tradicional.

Gestión de credenciales

No se detectaron Secrets en Secrets Manager ni credenciales en SSM Parameter Store en la evidencia revisada. Esto sugiere que las credenciales podrían estar en: - variables de entorno/archivos de configuración en hosts, - configuración de aplicaciones/CI, - o mecanismos externos al stack actual.
