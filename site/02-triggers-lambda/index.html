Triggers y Event Sources

Esta sección describe qué dispara a cada Lambda y cómo se integra con el resto del stack.

Tipos de triggers observados

  • EventBridge (CloudWatch Events): reglas que disparan tareas programadas y reencolados.
  • API Gateway: endpoints REST/HTTP y Authorizer.
  • S3 Events: notificaciones de buckets (ObjectCreated).
  • SES: procesamiento de correos entrantes.
  • SQS: event source mappings (mapeos cola→Lambda).

Integraciones cross-region

Se observa un patrón donde APIs en us-east-2 integran Lambdas en us-east-1. Esto es importante para migración porque obliga a migrar API + Lambda como un conjunto o ajustar integraciones para que queden en la misma región destino.
