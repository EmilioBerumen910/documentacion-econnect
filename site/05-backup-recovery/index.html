Backups, snapshots y recuperación

Backups automáticos

  • Backups automáticos: habilitados
  • Retención: 1 día
  • Ventana: 06:09–06:39 UTC (30 min)

Riesgos

  • Retención de 1 día = ventana corta para incidentes detectados tarde.
  • Sin política central de snapshots, hay riesgo de retención inconsistente y costos.

PITR (Point-in-Time Restore)

Disponible porque hay backups automáticos.
No hay evidencia de pruebas de restore/PITR.

AWS Backup / DLM

  • AWS Backup aparece configurado para ciertos recursos (p. ej. un EC2), pero no hay evidencia de cobertura para RDS econnectds1.
  • No se detectaron políticas DLM.

Snapshots cross-region

No hay evidencia de snapshots/replicación cross-region para RDS.
Hoy la replicación cross-region observada es principalmente en S3 (CRR).
