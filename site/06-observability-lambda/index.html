Observabilidad y operación

Qué asegurar antes del cutover

  • Logs en CloudWatch (retención definida y filtros por error).
  • Métricas y alarmas mínimas:
  • Errors, Throttles, Duration, ConcurrentExecutions, IteratorAge (si aplica).
  • DLQs / destinos de fallo:
  • Para SQS: redrive policy + DLQ
  • Para EventBridge: DLQ en target o mecanismo de retry/alarma
  • Correlación:
  • request IDs y trazabilidad end-to-end (especialmente en flujos API Gateway).

Nota: el reporte menciona faltantes de configuración (p. ej. schedules de EventBridge y DLQ no documentados), por lo que es importante capturarlos antes de migrar.
