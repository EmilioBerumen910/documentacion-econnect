VPCs y ubicación de instancias

Mapping por instancia (VPC)

  • vpc-0cda6f6b (nombre pendiente): Windows, Mongo-Primary, Mongo-Reports, SOLUCIONA, windows2, sews, sa31 c6
  • vpc-166c0773 (nombre pendiente): win_robots

Subnets y clasificación (us-east-1)

vpc-0cda6f6b

  • Subnets públicas (ruta default 0.0.0.0/0 → IGW):
  • subnet-0a083fd804a5d7647, subnet-eaa0f1c0, subnet-4b87863d, subnet-eebeecb6, subnet-b1ae9e8c
  • Subnets privadas (ruta default 0.0.0.0/0 → NAT):
  • subnet-0ef552d2118b2938a, subnet-028170afb4e27690a, subnet-0d2549cfe1b691e62

vpc-166c0773

  • Subnets observadas (todas públicas, por ruta principal 0.0.0.0/0 → IGW):
  • subnet-3b7caf10, subnet-48780a72, subnet-b3a034c4, subnet-5d65d104

Salida a Internet desde subnets privadas

  • Se confirma salida por NAT Gateway usando la route table privada rtb-023adfd6d8baafdcf con ruta 0.0.0.0/0 → nat-03f4861d918874e94.

Conectividad privada / on-prem

No se encontró evidencia de conectividad privada hacia/on-prem: - VPC Peering: no hay conexiones activas (se observó antes una ruta pcx-... en estado Blackhole, sugiriendo peering previo eliminado/roto). - Transit Gateway: no existe. - VPN (Client VPN / Site-to-Site): no existe (según revisión). - Direct Connect: no hay interconnects.

Puertos relevantes reportados (exposición)

  • 22/TCP (SSH): restringido a IPs específicas / SG interno.
  • 27017 y 27017–27030/TCP (MongoDB): reportado como abierto a Internet (0.0.0.0/0 y/o ::/0).
  • 28017/TCP: accesible desde SGs internos (admin/monitoring probable).
  • 8881/TCP: abierto a Internet (servicio por confirmar).

Network ACLs

  • NACL reportada como permisiva (ALLOW ALL); el control de tráfico real depende de Security Groups y de rutas/subnets.

Dependencias de allow-lists por IP (riesgo de migración)

Hay señales claras de dependencias por IP pública: - NAT Gateway con IP pública fija 3.226.159.167 (posible IP de salida allowlisteada por terceros). - 19 Elastic IPs y al menos una asociada directamente a una instancia (i-0b3731b503b53cedf), lo cual sugiere integraciones que dependen de IP fija.
