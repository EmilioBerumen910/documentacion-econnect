EventBridge

Resumen de qué hace en Econnect

EventBridge soporta automatizaciones batch, reprocesos, reglas de seguridad y eventos de infraestructura. La evidencia muestra una concentración casi total en us-east-1.

arn:aws:events:us-east-2:305968097757:event-bus/default us-east-2 default 0
arn:aws:events:us-west-1:305968097757:event-bus/default us-west-1 default 0

Arquitectura / flujo

EventBridge default bus us-east-1 -> Lambda / Inspector

Riesgos y gaps

  • 100% de la automatización visible depende de us-east-1.
  • No hay bus custom, cross-account ni cross-region routing.
  • Existe discrepancia de 37 vs 38 rules.
  • No se evidenciaron ARNs completos, DLQ ni retry policy por rule.

Runbook operativo

  1. Revisar si la rule sigue habilitada.
  2. Validar target actual.
  3. Revisar métricas Invocations / FailedInvocations.
  4. Revisar logs de Lambda.
  5. Si un proceso crítico falla, probar evento manual controlado.

Checklist de migración a mx-central-1

  1. Exportar reglas y targets completos.
  2. Clasificar reglas críticas por negocio.
  3. Replicar reglas en región destino.
  4. Replicar Lambdas y permisos.
  5. Probar eventos schedule y event pattern.
  6. Diseñar respaldo regional; hoy no existe evidencia de DR para EventBridge.

Cómo validar

aws events list-event-buses --region us-east-1
aws events list-rules --region us-east-1
aws events list-targets-by-rule --rule ENCOLAR_SIMULAR_ESTADOS --region us-east-1
aws cloudwatch list-metrics --namespace AWS/Events --region us-east-1

Cómo obtener la evidencia

aws events list-rules --region us-east-1
aws events list-targets-by-rule --rule <rule-name> --region us-east-1
aws events describe-rule --name <rule-name> --region us-east-1
aws events list-event-buses --region us-east-2
